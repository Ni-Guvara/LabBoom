# LabBoom · 高中物理三维交互实验系统

网页端三维交互实验系统，学生像进实验室一样按次第动手做实验，数据自动沉淀，最终拼出完整的必修物理知识体系。

- **内容底座**：人教版《普通高中教科书·物理》必修 第一册、第二册、第三册（2019 新课标）
- **技术栈**：Vite + React + TypeScript + three.js + zustand + ECharts + KaTeX
- **设计依据**：`douyin_analysis/高中物理三维交互实验系统-设计说明.md`（v1.2）
- **视觉基准**：`douyin_analysis/image/shiguang_*`（拾光视界深空玻璃壳层语言，见设计说明 §4.5）

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 纯静态构建到 dist/（离线可双击 index.html）
npm run preview  # 预览构建产物
```

## P1 力学线（L1、L3~L7）

力学线六个实验已统一为 L4 标杆同构实现：**真实尺寸参数化器具 → 布置/运行/分析三态 → 事件级数据表（≤15 行，带来源）→ 表格曲线双向联动 → CSV（含参数元数据）→ 结论判定**。

- **L1 研究匀变速直线运动**：气垫导轨 1.20 m（右端枢轴 + 垫片抬升 h）+ 滑行器 155 g + J0203 打点计时器 + 光电门 + 展开纸带；纸带 0.02 s 一点、5 点取 1 计数点；逐差法 `a=((x4+x5+x6)−(x1+x2+x3))/(9T²)` 与 v-t 拟合双路求 a，对比 `a=g·h/L`；判定 `a` 双路相对误差 <5%
- **L3 探究两个互成角度的力的合成规律**：木板 + 圆环结点 + 三只弹簧测力计（几何刻度）+ 细绳；等效替代法，`F合=√(F1²+F2²+2F1F2cosθ)` 与实测合力对比；≥3 组、误差 <5%，实测-理论 y=x 图
- **L4 摩擦力与 a-F 关系（力学标杆）**：J2183 小车 / J0203 打点计时器 / 光电门 / 定滑轮 / 砝码盘按真实尺寸建模；`a=(m0g−f)/(M+m0)`；纸带计数点事件表 + v-t 拟合求 a + 跨组 a-F 图 + 摩擦补偿开关（截距可视化）；判定 a 相对误差 <5%
- **L5 探究平抛运动**：35° 斜槽 + φ16 mm 钢球 + 5 cm 方格描迹板；频闪 0.05 s 留痕，`x=v₀t`、`y=Y₀−½gt²`；数据表含 `Δx`、`Δ²y`；x-t 与 y-t² 双图切换，`y-t²` 斜率求 g 与 v₀；判定 g、v₀ 误差 <5% 且 Δx 极差 <2 mm、|Δ²y| <2 mm
- **L6 向心力演示器**：转盘 + 手柄 + 小球 + 弹簧 + 径向测力计；控制变量 m/r/ω，`F=mω²r` 与实测对比；≥3 组、误差 <5%，F 与 mω²r 的 y=x 图
- **L7 验证机械能守恒**：铁架台 + 电磁释放夹（LED）+ 重锤 + 双光电门；`accel=g−(C/m)v²` 含空气阻力，ΔEp=mgΔh 与 ΔEk=½m(v2²−v1²) 对比；≥2 组、误差 <3%，ΔEp-ΔEk 对角线图

### 力学地基（各实验复用）

- `engine/physics/kinematics.ts`：一条轨迹派生纸带点距、计数点、中间时刻速度、光电门挡光读数（杜绝三套数据）
- `engine/materials.ts`：12 类 PBR 材质分区 + 接触阴影（金属/塑料/纸/玻璃可区分）
- `labs/_shared/instruments.ts`：`airTrack / board / cart / tickerTimer / photogate / pulley / weightStack / retortStand / plumb / releaseClamp` 参数化器具，1 unit = 1 m，`userData.spec` 带名称/外形尺寸/质量
- `engine/SceneHost.tsx`：PCFSoft 真实阴影 + RoomEnvironment 环境光照；左键落器材=拖拽、落空白=旋转、中键只导航、4 px 死区、双击/F 聚焦、`1/3/7/0` 视图预设、滚轮朝光标缩放
- 方案与验收断言见 `docs/力学模块改造方案.md`
