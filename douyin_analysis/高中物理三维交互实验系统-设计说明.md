## 1. 产品定位

**一句话**：一套网页端的三维（3D）交互实验系统，学生像进实验室一样按次第动手做实验，实验数据自动沉淀，最终拼出完整的必修物理知识体系。

三条设计公理（所有功能取舍以此裁决）：

1. **次第优先**：实验不是散落的玩具，而是一条有前置依赖的学习路径。未解锁前置实验时，后续实验入口灰显。
2. **动手出真知**：每个实验必须有"可操纵的变量 + 即时的物理反馈 + 自动记录的数据表"。禁止做成纯动画播放。
3. **一图一世界**：所有实验结束后，学生的数据汇入一张"知识地图"，地图随学习进度生长——这就是"构成知识系统"的可视化表达。

### 4.1 通用实验台框架（所有实验复用，v1.1 改版）

每个实验页面 = 固定五区（借鉴 CurtinBuilds 的「中央舞台 + 底部步骤 + 侧栏面板」三件套）：

```
├──────────────────────────┬───────────────────────────┤
│ ① 3D 主舞台               │ ③ 参数面板（锚定标注开关）    │
│  [宏观视图|微观视图] 一键切换 │  右上角抽屉式，滑块/旋钮      │
│  可旋转/缩放/聚焦；        │                          │
│  物体可挂悬浮标注(随镜头)   │  ③' 实时数据区             │
│                          │  表盘/坐标图/自动落表+CSV    │
├──────────────────────────┴───────────────────────────┤

└──────────────────────────────────────────────────────┘
```

窄屏（手机）时：③ 折叠为底部抽屉，①② 纵向堆叠。

### 4.2 交互原语（12 个实验全部由这些原语拼装）

1. **拖拽装配**：把器材（弹簧、小车、电表）从器材架拖到台面，吸附到锚点；接错位置物理系统拒绝工作并提示。
2. **参数滑杆/旋钮**：质量、力、角度、频率等连续量；电表挡位用**可旋转 3D 旋钮**（鼠标拖转）。
3. **矢量实时渲染**：力/速度/加速度/场强全部画成 3D 箭头，长度∝大小，可开关显示。这是全系统统一的视觉语言。
4. **时间操控**：全局时间轴可播放/暂停/0.1×~2×变速/单帧步进——平抛、落体类实验必备。
5. **频闪/轨迹留痕**：运动物体每隔 Δt 留一个残影球，对应课本"频闪照片"，残影可直接用来读数。
6. **虚拟仪表**：电流表/电压表/测力计表盘 3D 建模，指针按真实量程与内阻偏转，超量程打表（"打坏"可撤销）。
7. **数据自动落表**：每次读数（学生点击"记录"或自动采样）写入数据表；表格实时联动坐标图（如 U-I 图线自动拟合直线给出 E、r）。
8. **误差可视化**：提供"理想值 vs 测量值"双线对比，学生可调摩擦/电阻温度系数等误差源，直观看到系统误差来源。
9. **宏观↔微观双视图**（▸ CurtinBuilds 的左实拍/右分子分屏）：舞台顶部一键切换。物理场景对应关系——电阻率实验：宏观导线 ↔ 电子定向漂移动画；静电场：带电体 ↔ 电荷/电场线视角；电磁感应：线圈磁铁 ↔ 导体电子受洛伦兹力特写；平抛/落体：宏观轨迹 ↔ 速度/加速度矢量分解视图。切换时保留同一时间轴，两视图状态严格同步。
10. **可逆模式切换**（▸ 充放电式对比）：任何"条件对"做成一个双向开关——摩擦补偿开/关、有/无空气阻力、理想/实际电表、单缝开/关。切一次、看一次对比，数据区用同色系深浅两条线叠放对比。
11. **点击即解释**（▸ 点微粒看 Fe²⁺ 身份）：点击场景内任意对象弹出解释卡——点纸带上的点 → 显示该点瞬时速度与算法；点电荷 → 显示其受力矢量与来源；点器材 → 显示器材名与使用规范（对应课本实验器材表）。**一键计算**系列：一键拟合、一键算斜率/截距、一键求平均值，计算过程展示中间步骤。
12. **锚定标注**（▸ 拾光视界）：标签锚在 3D 物体上随镜头旋转跟随（sprite/occlusion 处理，被遮挡时半透明），而非固定屏幕角落；可在参数面板开关"全部标注"。胶囊统一格式「**名称 + 当前值 + 操作提示**」（如「入射角度 45°·改变」「三棱镜 折射率 1.50·↻」），提示词可点击直接联动参数面板。
13. **公式符号动力学**（▸ 拾光视界物理公式条 / physics-sandbox）：概念舱与演示剧场专用。右侧**符号抽屉**（m、g、F、v、ω、λ…按章过滤）拖入舞台后，符号按当前公式关系**自动组装并按规律运动**——拖入 GMm/r² 生成两球连线与椭圆轨道、Gv/c 沿轨道绕行带拖尾；底部胶囊自动标注当前公式名（「F = GMm/r²｜万有引力定律」）。学生拆走任一符号 → 运动立即失常，直观看到"公式各项缺一不可"。

### 4.3 物理引擎要求

- 力学实验优先用**解析解驱动**（匀变速、平抛、圆周直接按公式算轨迹），保证数值精确；仅在需要接触/摩擦细节时用轻量物理引擎（如 cannon-es）。
- 所有渲染用 **three.js**（r160+）；UI 层 React/Vue 均可，推荐 **Vite + React + TS + three.js + zustand**（状态：实验变量、数据表、进度）。
- 图表用 ECharts 或自绘 canvas（v-t、x-t、U-I 图必须支持数据点回放动画）。
- 移动端：单指旋转视角、双指缩放；变量面板在窄屏折叠为底部抽屉。

### 4.4 视觉规范（v1.1：双主题）

**主题 A「亮实验室」（默认，做题/测量态）**：浅灰白环境 + 高对比器材；矢量箭头色固定：力=红、速度=绿、加速度=橙、场强=紫、磁感线=蓝。
**主题 B「深色舞台」（概念舱/演示剧场用，▸ 拾光视界）**：深蓝黑背景 + 聚光灯打在实验装置上，玻璃质感器材 + 辉光光束（如三棱镜色散的光路），营造公开课投屏氛围。两主题一键切换，存储于用户偏好。

通用规则：
- 中文 UI，术语与人教版课本**逐字一致**（如"加速度"不写"加速率"），公式用 KaTeX。
- 左上角固定**学科徽章**（科目·学段·册次，▸ CurtinBuilds 的「初中化学」角标惯例，物理版如「高中物理·必修一」）。
- 每个实验场景首次进入有 10s 引导动线（相机飞行动画 + 步骤条三步提示）。
- 运动学量可视化时**箭头/光束/粒子三种表达**按对象类型选择：矢量→箭头、光路→辉光束、粒子流→发光小球流（▸ 拾光的光电效应粒子流）。

7. **顶部导航栏**：通栏玻璃导航——左：学科徽章 + 系统名 + 版本小标；右：知识地图 / 实验手册 / 主题切换 / 数据导出。

## 5. 单实验规格样例（L4，其余 11 个照此模板扩写）

```
id: L4  名称: 探究加速度与力、质量的关系  章: M4
场景: 水平长木板 + 小车(可挂配重) + 细线过定滑轮连沙桶；打点计时器在右端
双视图: 宏观=整车运动+纸带点迹；微观=小车受力分解视图(拉力/摩擦/重力矢量箭头)
可操纵变量: 沙桶质量 m0(0-200g 步进5g) / 小车质量 M(200-1000g) / 摩擦补偿开关(可逆切换)
测量输出: 纸带点迹(可放大读数, 点任意点→解释卡显示瞬时速度算法) → 自动算 a
         F≈m0g 显示在测力计(3D 表盘锚定标注)
探究任务: ①保持 M 定, 改 m0 测 5 组 a-F  ②保持 F 定, 改 M 测 5 组 a-1/M
数据区: a-F 散点图(一键线性拟合, 显示斜率) / a-1/M 散点图
结论校验: 学生勾选 "a∝F 且 a∝1/M" → 与拟合结果比对
步骤条: [1 装配(拖小车/挂线)]→[2 测量(10 组数据)]→[3 结论]  每步显示进度%
误差彩蛋: 未补偿摩擦时图线不过原点——引导学生解释截距(课本正文要点)
```

## 6. AI 生成工程约定

### 6.1 代码结构（生成器必须遵守）

```
src/
  engine/          # 场景管理、渲染循环、拾取、相机动画
  primitives/      # 4.2 的 12 个交互原语（各一个组件，P1~P12）
  labs/
    _template/     # 实验关模板（五区布局 + 生命周期）
    L1/ ... L12/   # 每实验一个目录: scene.ts / panel.tsx / data.ts / quiz.ts
  topics/          # M1~M13 章内容(概念舱文案、公式、检查点题库)
  graph/           # 知识图谱数据 + 知识地图场景
  modules/         # 多科目模块挂载点（见 §7）
  store/           # 进度与数据持久化(localStorage 起步, 预留后端)
content/
  curriculum.json  # §2 的全部结构化内容(章节/实验/依赖图/考点)
```

### 6.2 内容即数据

`curriculum.json` 单文件承载全部教学结构，AI 生成网站时**先写它再写代码**：

```json
{
  "subjects": { "physics": { "status": "active" }, "chemistry": { "status": "reserved" } },
  "chapters": [ { "id": "M4", "title": "运动和力的关系",
    "prereq": ["M1","M2","M3"],
    "sections": ["牛顿第一定律","实验:探究加速度与力、质量的关系","牛顿第二定律","力学单位制","牛顿运动定律的应用","超重和失重"],
    "labs": ["L4"] } ],
  "labs": [ { "id": "L4", "type": "group", "steps": ["装配","测量","结论"], "variables": ["m0","M","friction"] } ]

```

### 6.3 分阶段生成路线（给 AI 的施工顺序）

1. **P0 骨架**：curriculum.json + 知识地图 + 实验台框架 + L2（弹簧，交互最简单）跑通全流程。
2. **P1 力学线**：L1、L3、L4、L5、L6、L7 + 对应概念舱。
3. **P2 电学线**：L8~L12（重点做好虚拟电表与旋钮交互）+ M13 汇合章。
4. **P3 打磨**：演示剧场、误差可视化、章测验自动出题、移动端适配、**离线打包**。

每阶段验收：该阶段实验能"装配→测量→出图→勾结论→点亮星系"完整闭环。

**交付形态硬要求**（▸ CurtinBuilds：白板/电脑/平板/手机通用、浏览器直开、支持离线）：构建产物为纯静态站点（`vite build` 后单目录可 U 盘拷贝），教师无网环境下双击 index.html 即可用（本地字体+本地资源，不引外部 CDN）；进度数据 localStorage，预留 JSON 导入导出以便跨设备迁移。

## 7. 多科目模块预留（化学 / 生物 / 地理…）

### 7.1 架构原则：科目是插件，不是分支

- 顶层路由 `/{subject}/{...}`，每个科目一个 **manifest.json**（声明章节树、实验清单、依赖图、配色主题、器材库扩展）。
- 共享底座不动：实验台五区布局、12 个交互原语、数据落表、知识地图、进度系统全部复用。
- 科目注册机制：`modules/<subject>/manifest.json` 被加载后自动出现在首页科目选择器；`reserved` 状态显示"建设中"占位卡（可放简介与预告动画）。

### 7.2 三级导航（▸ 拾光视界的 学科→学段→模块，页面级规格见 §4.5）

首页科目选择器之上再加一层：**学科 → 学段（初中/高中）→ 模块（章/实验）**。本轮只实现"高中·物理"分支；其他分支显示建设中占位。目录树由各科 manifest 生成，前端不硬编码。三页一律用 §4.5 深空玻璃壳层语言：

- **L1 学科选择页**：左 hero（品牌位 + 主标题「学科可视化交互系统」+ 一句定位文案 + 直观/沉浸/精准/联动 四关键词组），右侧一张磨砂玻璃大卡「选择学科」内嵌 6 学科卡——物理可用，其余卡片加"建设中"小标占位（▸ 拾光的「敬请期待」惯例）。
- **L2 学段选择页**：衬线英文大标（Physics Curriculum.）+ 小标 ACADEMIC FRAMEWORK + 一句学段引导文案；两张学段玻璃卡（MODULE 01 初中学段 / MODULE 02 高中学段），卡内一段定位文案 + CTA（开启探究 → / 探索领域 →）；初中卡本轮灰化占位。
- **L3 模块列表页**：Hero 一句 slogan + §4.5-4 分类 Tab + 模块卡网格（封面=3D 场景缩略图，未解锁灰化加锁）；右上角常驻「知识地图」入口。

### 7.3 各科占位规格（本轮只写 manifest 骨架，不实现实验）

| 科目 | 预计形态 | 示例实验（写进 manifest 作预告） |
|---|---|---|
| 化学 | 分子/晶体 3D 拾取拼装 + 微粒动画 | 配制一定物质的量浓度的溶液；原电池；中和滴定 |
| 生物 | 细胞/器官剖切漫游 + 过程模拟 | 显微观察类；稳态调节过程 |
| 地理 | 地球/大气 3D 场景 + 参数演化 | 大气环流；洋流；地貌演化 |
| 数学/信息技术 | 预留 | 由 manifest 扩展，底座不变 |

### 7.4 底座为多科目预埋的三个钩子

1. 数据表 schema 通用（变量名-数值-时间戳），任何科目的"测量"都能落。
2. 知识地图星系由 manifest 的章节树生成，不硬编码物理章名。
3. 器材库按科目命名空间隔离（`physics.spring` / `chemistry.burette`），互不污染。
