## 1. 通用建模约定（不遵守会返工）

### 1.1 尺度与坐标系
- **1 Blender 单位 = 1 米**。所有尺寸用 mm 读，建模时 ÷1000。
- 导出 glTF：**Y-up、Apply Modifiers**（Blender 里是 Z-up，导出器自动转）。
- **原点放在「底面接触中心」**：器材落地/落台面时，直接把 `root.position.y = 台面高度`，不允许再补偿。
- 朝向：**器材的「正面/操作面」朝 +Z，长度方向沿 X**，实验台在 -Y 侧。例外：滑行器、小车沿 X 运动。
- 对称优先：左右对称的件用镜像，别两侧各建一遍（容易差 1 mm）。

### 1.2 材质色板（必须与 `src/engine/materials.ts` 对齐）
| 键 | Hex | metalness | roughness | 用在哪 |
|---|---|---|---|---|
| `aluminum` | `#a9a9a7` | 0.90 | 0.56 | 导轨型材、斜槽、砝码盘 |
| `aluminumMatte` | `#8e8e8c` | 0.85 | 0.62 | 大平面铝件（转盘、端板） |
| `steel` | `#9b9b99` | 0.96 | 0.42 | 立柱、螺栓、振片、轴、弹簧 |
| `brass` | `#c9a227` | 0.92 | 0.30 | 接线柱、进气嘴、配重 |
| `copper` | `#b87333` | 0.92 | 0.33 | 线圈、电磁铁芯 |
| `plasticRed` | `#d8412f` | 0.04 | 0.46 | 红旋钮、指针、挡板 |
| `plasticGray` | `#8b95a1` | 0.04 | 0.52 | 光电门壳 |
| `plasticBlack` | `#2b3038` | 0.06 | 0.50 | 计时器胶木座、轮子、手轮 |
| `glass` | `#dfeefc` | 0.00 | 0.04 | 测力计透明壳 |
| `rubber` | `#1f2328` | 0.00 | 0.92 | 地脚、缓冲垫、轮胎 |
| `wood` | `#6b4a26` | 0.00 | 0.82 | 长木板、实验台 |
| `paper` | `#c6bba0` | 0.00 | 0.95 | 纸带、白纸、细线 |
| `paintWhite` | `#d9dde1` | 0.00 | 0.58 | 平抛演示仪板面、滑轮支架 |

**材质分区原则**：一件器材至少要有 3 类材质（金属 / 塑料 / 橡胶或纸），否则会渲成一坨同色块。金属件必须单独给 `steel` 或 `aluminum`，不要用同一个灰。

### 1.3 光照与贴图
- **不烘焙光照**，不导出灯光。场景的 `studioEnvironment()` 提供 PMREM，glb 只出 baseColor / metallic / roughness / normal。
- 刻度、丝印、标签一律走**贴图**（64–256 px 的小图足够），但**毫米刻线要几何做**（细长盒体或 InstancedMesh），否则近景糊。
- 表面瑕疵（划痕、指纹、掉漆）**只在需要特写的主器材上加**，用 roughness 贴图轻微扰动，别用 color 贴图画脏点——会被误会成模型错误。
- 透明件（测力计壳、比色皿类）用 `glass`，`env` 降到 0.6，否则一片死白。

### 1.4 命名与可拾取性
- 每个可被点击/需要独立动画的部件，**单独成对象**，命名 `xxx__part`（`lab_common.py` 的 `attach(name)` 已封装）。
- 必须存在的**约定名**（代码按名字取，改名会静默失效）：
  - `tape` —— 打点计时器纸带（L1/L4 用 `hideParts(timer,'tape')` 换成动态纸带）
  - `flag` —— 滑行器/小车的挡光片（L1 按名字取挡光时刻）
  - `shade` —— 重锤遮光片（L7）
- `userData.spec = { name, size:[x,y,z], mass }` 要写到**根节点**，前端拿它做锚点与断言。
- 面数预算：单件 **≤ 8k 三角面**；一次场景出 3 件时合计 **≤ 20k**。当前打点计时器 5.3k / 导轨 6.2k 是标杆。

### 1.5 四个必检项（每次导出都跑）
1. `blender/inspect_glb.py <file>.glb` —— 底面 y=0、命名、材质复用、面数。
2. `blender/render_preview.py --view iso` —— 造型对照参考图。
3. `blender/render_preview.py --view section --ortho` —— 截面类（导轨/滑行器）必看。
4. 接进场景后 `node scripts/probe-pick.mjs <id>` —— 逐部件点击命中率。

## 2. 逐件规格

### 2.1 打点计时器 J0203（图 02 + 图 00）〔已建模：`build_ticker_timer.py`，39 部件 / 5.3k 面 / 308 KB〕

**总体**：144×70×60 mm（长×宽×高），黑色胶木底座 + 竖直磁极座，右侧立柱带蓝色极性旋钮，左端双限位卡引导 17 mm 纸带，纸带经复写纸圆盘上方、由振针打点。

**辨识三特征**（缺一个就不像）：① 竖立的黑色方板 + 横穿它的银白螺钉；② 白色横卧线圈 + 两端圆磁极片夹着薄振片；③ 底座上那盘黑色复写纸（φ30，最容易被漏掉）。

| 部件 | 几何 | 尺寸〔实测/目测〕 | 材质 | 细节要求 |
|---|---|---|---|---|
| 底座 | 圆角盒 | 144×70×8〔实测〕 | `plasticBlack` | 四角 R2；前缘左侧开 20 mm 宽纸带导槽；底面 4 个 φ6×2 橡胶脚 |
| 磁极座（立板） | 竖立方板 | 90×60×12〔目测〕，立起后顶面 y≈62 | `plasticBlack` | 正面上下各一颗 M4 滚花螺钉（`steel`，头部 φ8，露出 3 mm），**必须能看见** |
| 线圈骨架 | 横卧圆柱 | φ26×30〔目测〕 | `paintWhite` | 两端有 3 mm 挡边；中间绕线区域深 20 mm，可加 0.3 mm 环向条纹 |
| 磁极片 ×2 | 圆盘 | φ30×3，**中间留 2 mm 气隙** | `steel` | 气隙是振片通道，不能贴合 |
| 振片 | 薄板 | 70×12×0.5，向 +X 悬伸 | `steel` | 根部夹在磁极座与磁极片之间；末端略上翘 1.5°（预紧） |

| 立柱 + 极性旋钮 | 圆柱 | 立柱 φ10×35；旋钮 φ32×14 | 立柱 `plasticBlack`，旋钮 `plasticRed`（图里是深蓝，用 `#2b4a8b` 单列材质） | 旋钮顶面内凹 2 mm，侧面竖向滚花 24 条；旋钮下六角锁母对边 14 |

| 纸带 | 长条 | 宽 17×0.07〔实测〕 | `paper` | 从限位卡穿入、经复写纸上表面、向 -X 引出 200 mm；**名字必须叫 `tape`** |

**局部细节清单**：底座右下角丝印 `J0203`（8 mm 高，浅灰 `#8a8f96`）；底座侧面有一道合模线；振片根部两颗 M3 螺钉；线圈两端引出线（φ1 红黑各一根，绕到接线柱）。

**当前状态**：已建模并接入 L1。**已知偏差**：振针到复写纸的间隙未做精细控制（视觉上针尖顶在盘上），纸带进入方向与限位卡略偏 1 mm。修形时优先这两处。

### 2.4 光电门（图 03）〔已建模：`blender/build_photogate.py`，长杆 / 台式两版〕

**总体**：黑色 ABS 一体壳，U 形，槽口 50 mm；一侧发射、一侧接收；侧面双芯线 1.5 m + 3.5 mm 插头；顶部/侧面有数显窗。

**辨识三特征**：① 明显的 U 形开口（**必须真的通**，挡光片要穿过去）；② 一侧的深红发射窗 + 另一侧红 LED；③ 那根粗黑线和音频插头。

| 部件 | 几何 | 尺寸〔实测/目测〕 | 材质 | 细节要求 |
|---|---|---|---|---|
| 外壳主体 | U 形（两块侧板 + 底梁） | 60×70×30，槽口 50〔实测〕 | `plasticBlack`（roughness 0.55） | 四角 R3；槽内壁做消光竖纹；外侧有合模线 |
| 发射窗 | 圆窗 | φ6 凹 1 mm | `plasticRed`（深红 `#5b1a1a`，emissive 微弱） | 内嵌 φ3 红外管（`#3a0a0a`） |
| 接收窗 | 圆窗 | φ6 | `glass` | 中心 φ2 感光管 |
| 指示灯 | 小球 | φ2.5 | `plasticRed` emissive `#772211` | 挡光瞬间可亮（前端控制 emissiveIntensity） |
| 数显窗 | 平面 + 贴图 | 30×11 | `textPlate` | 显示 Δt（ms）；**做在器材面板上，不走悬停标注** |
| 线缆 | 软管 + 插头 | φ4×1500，插头 φ6×35 | `rubber` + `plasticBlack` | 从壳体下方出线，自然垂 80 mm 后出画面；插头有 2 道金属环 |

| 规格 | post | gap | 光轴 | 用途 |

**当前接入**：L1、L4、L7 全部用 glb（数显由 `attachGateReadout()` / `makeGate()` 运行时贴片，glb 不烘文字）；`instruments.ts` 的 `photogate()` 与 `L7/scene.ts` 的 `fallbackGate()` 保留作 fallback。

| 重锤遮光 | 子节点 `shade` | `L7/scene.ts` |
| 面板读数 | 留出平面（不需要建模数显），前端贴 `textPlate` | `instruments.ts: photogate(...).userData.setReadout` |
| 降级兜底 | 无 | `_shared/models.ts: loadOrFallback(id, fallback)` |

**新增器材的接入四步**（照 L1 抄）：
1. `build_xxx.py` 建模 → 导出 `public/models/xxx.glb`
2. `inspect_glb.py` 校验 → `render_preview.py` 装配确认
3. 场景里 `const m = await loadOrFallback('xxx', () => 程序化版本)`
4. `node scripts/probe-pick.mjs` + `shot-closeup.mjs` 自检

## 5. 造型评审清单（交付前自查）

- [ ] 拿参考图并排看，**三米外能否一眼认出是哪件器材**（辨识三特征齐不齐）
- [ ] 底面贴台面，**没有悬空/穿模**（`inspect_glb` + 场景截图双查）
- [ ] 同一画面里能分出 **≥3 类材质**（金属高光 / 塑料哑光 / 橡胶或纸）
- [ ] 所有可动件**单独命名**，约定的 `tape` / `flag` / `shade` 存在
- [ ] 近景（0.3 m 距离）看：刻线不糊、螺钉有、圆角不崩、透明件不通透成白片
- [ ] 面数 ≤ 8k/件；材质数 ≤ 12 种
- [ ] 参数化件（弹簧形变、挡光片宽度、砝码质量）能改一个参数就整体成立，**没有写死的几何**
- [ ] 与程序化 fallback 版**外形同量级**（切换时不能"跳一下"）
