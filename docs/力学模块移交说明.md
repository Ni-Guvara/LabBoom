## 三、建模规范（已定，必须遵守）

- **1 单位 = 1 米**；glb 导出 Y-up、Apply Modifiers；**原点在底面接触中心**。
- **例外：夹持类器材原点 = 被测点**（如 L7 `drop_gate.glb` 取光轴与落体线交点，前端 `position.y = 门高` 直接摆）。这类器材在 `inspect_glb.py` 的 `ORIGIN_EXEMPT` 里登记，免得被"底面没落在 y=0"误判。
- **不烘焙光照**：只出 baseColor/metallic/roughness/normal，光照交给 `studioEnvironment()` PMREM 影棚。
- 部件命名 `xxx__part`；滑行器挡光片**必须叫 `flag`**（L1 靠名字取挡光时刻）。
- 导出后跑 `blender/inspect_glb.py` 校验：底面 y=0、命名、材质复用、面数。
- 预览验证：`blender/render_preview.py --view iso|section --ortho --add "path@x,y,z" --hide`。

## 四、代码地图

### Blender 侧（`blender/`）
- `lab_common.py`：几何原语 `box/cyl/torus/rod_between/hexnut/prism/box_array/disc_array` + `make_root/attach/export_glb`。
- `build_ticker_timer.py`：39 部件 / 5,316 面 / 308 KB / 10 材质。
- `build_air_track.py`：一次出两个 glb —— `air_track`（1276 mm，27 部件，气浮孔、刻线、可调地脚、弹簧挡板）+ `sled`（172 mm，10 部件，倒 V 槽与导轨共用 SLOPE_ANG、配重槽、flag）。
- `build_l4_kit.py`：一件脚本出 `wood_board` / `trolley` / `sand_bucket` 三件。
- `build_throw.py`：`thrower.glb`，平抛实验器整机 75 部件 / 10.0k 面 / 538.5×300×432 mm。白底板 + 包边演示板 + 斜槽（水平导出段 115 + 上斜段 187@52°）+ 电磁释放器 + 全宽接球槽 + 亚克力挡条。**刻度尺故意不烘进 glb**，由 `L5/scene.ts` 的 `rulerMesh()` 用 canvas 画（数字清晰、可改量程）。
- `build_centripetal.py`：`centripetal.glb`，向心力演示仪 79 部件 / 27.7k 面 / 430.4×228×326 mm。桥形高底座（腿高 62 藏手轮）+ 三级塔轮 φ170/155/140 + 红皮带 + 螺纹立柱 + 曲柄手轮 + 备用球座。横臂由前端程序化生成。
- `build_drop_gate.py`：`drop_gate.glb`，自由落体用落体式光电门 27 部件 / 3.6k 面 / 307×97×55 mm。**竖叉口净空 46 mm（容 40 mm 遮光片）+ 后方数显盒 + 横臂与十字夹**；原点 = 光轴交点，所以 `inspect_glb.py` 里登记了 `ORIGIN_EXEMPT`。读数面 40×14 mm 留白，由 `L7/scene.ts` 的 `makeGate()` 贴 canvas。
- 产出的 glb 在 `public/models/`（由 three 端加载）。

### 前端引擎（`src/engine/`）
- `loader.ts`：`loadApparatus(id)` → `{ root, parts: Map, size }`；**多材质网格父级回退**（`tape` → `tape_1/tape_2`）。
- `SceneHost.tsx`：**相机的唯一主交互是左键拖动旋转**（滚轮朝光标缩放、右键/中键平移）。
  画布上要同时掐掉 `selectstart` / `dragstart` / `contextmenu` / `wheel` 的默认行为并设 `touch-action:none`，
  否则按住左键滑动会选中文字、触控板横扫会触发浏览器返回手势，表现成"转着转着页面跟着跑"。
  拖拽系统是本模块重点，刚重构过：
  - `draggable(root, { plane: 'floor'|'vertical', canDrag: () => bool, onMove })`；Shift = 垂直升降。
  - **增量式拖动**：用「射线交点位移增量」+ 父级世界四元数逆变换回局部坐标。直接赋世界交点会让挂在 group 下的器材一拖跳半米——这是踩过的坑，别改回去。
  - `pickAt(x,y)` 调试口返回命中祖先链；`window.__labboomScene = { scene, camera, controls, dragRoots, renderer, pickAt }` 供自检脚本用。
- `_shared/models.ts`：`loadOrFallback(id, fallback)`（glb 加载失败自动用程序化模型兜底，建模进度与实验可用性解耦）、`partOf`、`hideParts`。
- `_shared/instruments.ts`：程序化器材库。光电门已改「顶梁+两垂臂」真通光口；`tableTop` 台面**已去粗糙度贴图**（256px 噪点铺 2.4 m 会放大成 2 mm 深点，被误认成打点）。
- `_shared/framing.ts`：`fitCamera` 取景；`userData.noFrame = true` 的对象不参与包围盒（纸带垂落段必须设，否则把镜头拽远）。
  `fitCamera` 会把 `{ box, opts }` 记进 `camera.userData.__fit`，`refitCamera(camera)` 据此按**当前 aspect 重放**——
  进出全屏、窗口拉宽后靠它回到"完整、居中、大小合适"，不用各实验再传一遍美术参数。
- `_template/LabFrame.tsx`：**实验台布局 v2**，12 个实验共用，改一处全站生效：
  - 3D 舞台铺满 `calc(100dvh - 58px)`（TopNav 高度锁死 58 px，动导航高度必然溢出滚动条）；
  - 「实验操作 / 数据记录 / 数据绘图 / 结论校验 / 全屏」= 右侧悬浮按钮，点开滑出抽屉，再点同一项收起（手风琴，默认全收）；
  - 新增 `chart?: ReactNode`：给了才出现「数据绘图」按钮（原来数据表和图挤在 `dataArea` 里）；
  - **抽屉必须始终挂载、用 transform 滑出**：条件渲染会卸载 ECharts 容器，实例指向已脱离文档的 div，图直接空白；
  - 抽屉占宽通过 `window` 事件 `labboom:inset` 通知 3D 引擎，SceneHost 用 `camera.zoom` + `setViewOffset`
    把器材缩进"没被遮住的可见区"并居中——开抽屉时器材不会藏在面板下面。

## 五、L1 已达到的程度（验收基准）

**物理正确性**：
- 纸带**穿过计时器针口**、末端压在滑行器尾部压片下（不是飘在桌上）；打点随位移逐点打印**在纸带上**（普通点 φ3.2 mm、计数点 φ8 mm，每 0.02 s 一点、5 点取 1 计数点）。
- 光电门是**真挡光计时**：挡光片前缘进入→离开才累计 Δt；数显牌定格显示 **Δt（ms）**，v = d/Δt 换算写在悬停标注里——不要把 v 直接当读数，学生要看得出原理。
- 逐差法 bug 已修：原实现把**位置当位移**（误差 250%），现按相邻位移算，结果与理论值差 0.00%。
- v-t 拟合 a ≈ 理论 a = g·h/L（R²=0.998）；垫片高度 h ↔ 倾角联动，参数一改即归零重算。
- 导轨绕右端 pivot 抬起时，计时器 C 形支架、光电门立柱有**落地补偿**（`benchYAt`），不会悬空。

**交互**：setup 阶段可拖（计时器/光电门沿导轨），运行态锁定。

**已修掉的坑清单**（别再踩）：BoxHelper 吃射线拾取（设 `raycast=()=>{}`）；多材质网格拆名；prism 原点在 (0,0,0) 导致投影落地面；V 槽倒角削掉滑行器最低点（bevel=0）；俯角 16° 三角截面被压扁（26°）；台面斑点纹理误认为打点；VSM 阴影麻点（调参后回退保留 VSM，参数见 `studio.ts`）。
