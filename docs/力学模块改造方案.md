# 力学模块改造方案（P0 地基 → P3 标杆）

> 目标：把力学线从"能看"改到"可信 + 可查 + 可操作"。三件事缺一不可：
> ① 物理自洽（一条轨迹派生所有测量量）；② 器材具体（真实尺寸/材质/结构件）；③ 交互定案（左键拖器材、中键只做导航）。

---

## 1. 素材调研结论（决定建模路线）

| 素材源 | 授权 | 结论 |
|---|---|---|
| Poly Haven | CC0 | 只有环境/道具（HDRI、木桌、金属板），**没有**气垫导轨、打点计时器、光电门；可作环境光照与 PBR 贴图来源 |
| ambientCG | CC0 | PBR 材质（拉丝铝、橡胶、木材）可用 |
| Sketchfab CC0 筛选 | CC0（需逐个核） | 教学器材极少，模型多为低模展示件，比例/结构不可信 |
| Kenney / Quaternius | CC0 | 游戏低模风格，与"做真实实验"目标冲突 |

**决断**：器材一律**程序化参数化建模**（几何 + PBR 分区），尺寸取自厂商规格；外部素材只用于环境光照与贴图。
理由：国产教学仪器没有可靠的 CC0 模型，且程序化模型才能满足"参数可调（挡光片宽度、量程、砝码质量）"和"几何刻度放大不糊"。

**已采用的真实规格（建模基准，1 unit = 1 m）**

| 器材 | 规格 | 用途 |
|---|---|---|
| 气垫导轨 | 工作面 1200 mm、脚距 600 mm、进气口 φ30 mm、滑行器 121 mm / 155 g、浮高 ≥0.10 mm | L1 |
| 轨道小车 J2183 | 轨长 900 mm、轨距 50 mm、小车 200±10 g、配块 10 g / 50 g | L4 |
| 电磁打点计时器 J0203 | 0.02 s（50 Hz）、AC 6 V、外形 144×70×60 mm、阻力 ≤3 g、纸带 17 mm | L1 / L4 |
| 光电门 | U 形槽 50 mm、立杆高度可选（导轨用短杆）、挡光片 10/50 mm | L4 |
| 定滑轮 / 砝码 | 轮 φ50 mm、砝码按钢密度 7.8 g/cm³ 反推体积 | L4 |
| 米尺 / 刻度 | 1 cm 长刻线、5 mm 短刻线，**几何绘制**（不用贴图） | 全部 |

## 2. 物理内核（已完成）

新增 `src/engine/physics/kinematics.ts`，数据流单向：

```
受力模型 accel(s) ──simulate()──> Sample[] 轨迹
                                     ├─ tapePoints(0.02 s)  ─> 纸带点距
                                     ├─ countingPoints(5)   ─> 计数点（0.1 s）
                                     ├─ tapeVelocities()    ─> v_n=(x_{n+1}−x_{n−1})/2Δt
                                     ├─ gateReadings()      ─> v=d/Δt（挡光时间由轨迹推出）
                                     └─ sampleAt(t)         ─> 三维动画位置（每帧）
```

硬约束（验收断言）：
- 动画位移 = 积分位移 = 纸带点距积分，误差 < 0.1%；
- 光电门读数与同一时刻真实速度相对误差 < 0.5%（挡光片 10 mm 时可放宽到 1%）；
- 改变 M/m0/摩擦补偿后，全部读数同步变化，不允许任何"写死的常数"。

## 4. 场景渲染与交互（已完成）

`src/engine/SceneHost.tsx`：
- 阴影：`PCFSoftShadowMap` + SpotLight 投影（1024）+ `normalBias`，器材必须 `castShadow` 且台面 `receiveShadow`；
- 环境光照：`RoomEnvironment` → PMREM，金属/玻璃才有反射层次；
- 交互分流：`pointerdown` 捕获阶段先射线拾取
  - 命中已注册器材 → `stopImmediatePropagation()`，进入拖拽（4 px 死区，`pointercapture`，Shift 垂直）
  - 未命中 → 交给 OrbitControls（左键旋转）
  - 中键/右键永远只做导航；滚轮 `zoomToCursor` 朝光标缩放
- 聚焦与预设：双击器材 / `F` 聚焦（包围球取景 + 缓动），`1/3/7/0/Home` 前/右/顶/复位。

已知取舍：拖拽期间不做物理约束（器材可移出台面），后续在 `DragOptions` 里接碰撞与吸附点。

## 5. 数据与图表规范

- **事件化**：一行 = 一次可测量的物理事件（纸带计数点 / 光电门读数），单次实验 ≤15 行；
- 每行带 `来源` 字段（`纸带·中间时刻` / `光电门 v=d/Δt`），禁止出现无来源的综合值；
- 表格 ↔ 曲线双向联动（点行高亮曲线点，点曲线反选行）；
- 分析页必有三项对比：拟合值、理论值、相对误差 + R²；系统误差（未补偿摩擦）单独提示；
- 每次测量记录一组（组次），跨组图 a-F 才能看出规律；导出 CSV 含参数元数据行。

### 7.3 器材真实度与交互规范（本轮 7 条纠错落地）

**建模规范**

| 项 | 规范 | 典型落地 |
|---|---|---|
| 比例 | 1 unit = 1 m，器材按真实规格给尺寸，**不做"显示用放大"** | 弹簧自由长 0.16 m、砝码 φ30 mm、光电门叉口 60 mm |
| 活动量 | 物理量 1:1 映射到几何：伸长量、抬升高度、下落位移都由公式直接驱动 | L1 `h=0.9sinθ`、L2 `len=L0+n·m₀g/k`、L7 双门高度直读 `gate2Y` |
| 连接 | 绳/丝必须**两端都接到实体**（挂钩点用 `hookOffset` 显式给出），不允许悬空或穿模 | L4 绳 → 小车前钩 + 滑轮顶弧 + 砝码盘顶环；L3 绳 → 测力计挂钩 |
| 读数 | 器材自带面板用 `textPlate()`（`MeshBasicMaterial`，不受影棚光照、常显），不走悬停标注 | 光电门数显、测力计读数、L6 中心 `F=mω²r` 数显 |
| 细节 | 每类器具至少具备"能被认出来"的结构特征 | 小车四轮+车轴、滑轮轮缘弧段、光电门两爪+红外窗+手轮、转盘滑槽刻度 |
| 暗部 | 纯黑塑料在背光侧会糊成黑影，结构件改用中灰工程塑料（`0x555e68`） | L7 光电门叉头、L6 弹簧改深色钢丝 |

**交互规范**

1. **标注默认隐藏**：所有 `addAnchor` 的器材标注初始 `opacity: 0`；光标在器材上停留 **2 s**（`HOLD_MS`）才淡入，移出即隐藏，拖拽过程中不弹出。
2. **面板 ↔ 器材单向实时同步**：`onTick` 每帧从 `getState()` 读参数写几何，**不依赖"下次运行"**。参数一变，器材位置/长度/读数当帧更新（L7 光电门高度、L2 弹簧长度、L6 半径与角速度均按此实现）。
3. **参数映射必须一一对应**：每个滑杆只驱动它名下那一个自由度；改高度不得改动质量，反之亦然（L7 曾把 `gate2Y` 写进重锤高度的分支，已修）。
4. **换参数即重置运动状态**：布置阶段调参后 `simT=0 + resetMotion()`，避免"改垫片看起来像挪小车"。
5. **构图**：`fitCamera(camera, boxOfSubject(scene), {...})` + `setTarget(...)` 成对使用；台面/后墙打 `userData.noFrame` 不参与包围盒。

**已知限制（待定参数）**：L2 按 `k = 40 N/m`、每片 100 g 的"实验给定"取值，每挂一片只伸长 Δx = 2.45 mm（相对原长 1.5%），1:1 渲染下肉眼几乎看不出弹簧变长（教学上常见的演示弹簧是 k≈10 N/m + 50 g 砝码，每片约 49 mm）。当前只保证"物理正确 + 托盘与砝码堆随之下降"，若要让伸长量明显可见，需要把该实验的 k / m₀ 改为演示规格——属实验参数变更，待确认后同步 `L2/index.tsx` 与数据表。

## 8. 风险

- `SceneHost` 是所有实验的公共容器：本次改动会影响 L1–L12 的外观（环境光更亮、相机初值变化），需逐页回归；
- 拖拽用屏幕位移映射到台面，斜视角下存在轻微跟手偏差，后续可改为射线-平面精确交点（已实现平面交点，保留死区）；
- 器材 `userData` 结构尚未类型化，建议 P2 引入 `Instrument` 接口并给 `userData.spec` 加类型。
