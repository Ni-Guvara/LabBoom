## 三、录制与字幕建议

1. **Hook 重复两次不同处理**：第一次人声偏干、贴近耳朵；第二次加短延迟 + 半拍混响，副歌才有"抬头"的感觉。
2. **Verse 的节奏重音压在实验动作上**：如"后三减前三"、"挡光时间 d 比 Δt"，重音落在数字上，字幕同步放大该数字。
3. **Bridge 提速**：BPM 不变，但每句字数加密，配字幕逐条弹出（每条配一个图标：控制器 / 天平 / 卡片 / 折线 / 误差箭头）。
4. **数字字幕规范**：Δx、Δ²y、gT²、mω²r、ΔEp/ΔEk 用等宽或公式字体，别用普通黑体，否则上标会糊。
5. **尾帧落版**：LabBoom 标识 + 一句话 slogan：**"公式，从此有了形状。"**

## 四、知识点校验表（每句都能对上教材）
